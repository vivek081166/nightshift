According to the **Deploying with Shipyard** guide, `payments` deploys and rolls back
through **Shipyard** (not the old deploy tool). As on-call, you are pre-approved to roll
back to the immediately preceding release without additional approvals.

You can roll back using either the CLI or the web UI:

### Option 1: Command line
1. Find the release just below the `live` one:
   ```bash
   shipyard releases payments
   ```
2. Initiate the rollback to that release (replace `r-XXX` with the target release
  number, e.g., `r-211`):
   ```bash
   shipyard rollback payments --to r-XXX
   ```
3. Type the service name (`payments`) when prompted to confirm.

---

### Option 2: Browser
1. Go to `shipyard.sorrel.internal`.
2. Select **payments** and open the **Releases** tab.
3. Find the release directly below the `live` one and click **Roll back to this
  release**.
4. Type `payments` in the box to confirm.
