According to the **Payments rollback runbook**, here are the exact steps to roll
payments back:

### 1. Before you start
* **Check the cause & money movement**: Make sure latency/checkout failures started
  after the deploy (not before, which would indicate card provider issues). Verify money
  has not moved wrongly (if charges/refunds are being counted twice, stop and page Mei).
* **Communicate**:
  * Open a thread in `#inc-live` stating you are about to roll back payments.
  * Post one line in `#deploys`: `"reverting sorrel/payments to d-XXXX"` so nobody
    starts another deploy while the lock is held.

---

### 2. Find the target deploy ID
On your laptop, run:
```bash
dtool history sorrel/payments --last 5
```
* The newest deploy at the top is the bad one.
* Note the deploy ID directly below it (e.g., `d-3917`). That is the version you are
  rolling back to.

---

### 3. Run the rollback
Run the revert command pointing to the previous deploy ID, including the mandatory
`--drain-checkouts` flag:
```bash
dtool revert sorrel/payments --to <previous deploy id> --drain-checkouts
```
