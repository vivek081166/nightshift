As of **2026-09-28**, **payments** (along with `api`) moved to **Shipyard**. The old
deployment tool (`dtool`) can no longer roll payments back.

Rolling back payments to the previous release is pre-approved for the on-call engineer
and does not require an approver.

### Option 1: Via the Command Line
1. Check the recent releases to identify the release immediately below the `live` one:
   ```bash
   shipyard releases payments
   ```
2. Run the rollback command pointing to that previous release (for example, `r-211`):
   ```bash
   shipyard rollback payments --to <previous-release-id>
   ```
3. Type the service name (`payments`) when prompted to confirm.

### Option 2: Via the Browser
1. Go to `shipyard.sorrel.internal`.
2. Select **payments** and open the **Releases** tab.
3. Find the release immediately below the `live` one and click **Roll back to this
  release**.
4. Type `payments` in the confirmation box to confirm.

---
