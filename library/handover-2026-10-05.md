- **Severity:** P2
- **Channel thread:** `#inc-live` (thread: `20261002-payments-validation`)
- **Impact:** Checkout submissions in `ap-northeast` and `us-east` saw elevated validation failures for client-submitted postal code formats on custom salon checkout forms. No duplicate charges occurred, no card data was mishandled, and settled provider transactions remained consistent.
